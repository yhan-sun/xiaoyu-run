# 小雨run · Desktop（Rust + Tauri）

> 极简、克制的校园运动客户端。轨迹计算与协议全部在本地完成。

这是 v3 的完整重写：原 Android/Kotlin 版本保留在仓库根目录的 `app/`，
新的桌面客户端在这里，用 **Rust 承担全部计算与网络**，前端只负责呈现。

---

## 为什么重写

| | Kotlin 版 | Rust 版 |
|---|---|---|
| 轨迹生成 | 在 UI 线程外跑，二分标定约 70 次 × 上千点 | 同样算法，亚毫秒级，可**实时预览** |
| 协议 | `HttpURLConnection` + `org.json` 手工拼 | 类型化响应 + 统一错误面 |
| 状态 | Activity + 前台服务 + WakeLock 保活 | 进程内线程，无保活问题 |
| 视觉 | XML 布局 + 自定义 View | 完整控制的设计系统，深浅色双主题 |

Rust 版真正的红利是**交互**：拖动配速滑块时，围栏内的轨迹形状是**立刻重算重绘**的。
这在原来的实现里做不到 —— 一次标定要几百毫秒到数秒。


## 开发与构建

```bash
cd desktop
npm install

# 开发（热重载）
npm run app

# 打包 macOS .app
npm run app:build

# 只跑 Rust 侧测试
cd src-tauri && cargo test
```

> 若 `~/.cargo` 不可写，可把缓存重定向到工作区内：
> ```bash
> CARGO_HOME=../.cargo-home cargo test
> ```

## 轨迹引擎

与原 Kotlin 实现同构，但用显式结构体替代闭包捕获。

1. **配速标定**：采样点数由「配速 × 距离」唯一确定（2 km @ 5'45" = 690 点），
   二分反解地面步长，使**实测距离等于目标距离** —— 否则噪声会把距离撑长十几个百分点。
2. **围栏内缩**：从 0.90 起逐档向内试，取第一个基准环完全合法的档位；
   全部非法时退到违例最少的一档，再逐点兜底回缩。
3. **有机化**：六条整数圈正弦（2/3/5/7/11/17 圈）+ 3~5 处局部鼓包 + 一轮滑动平均，
   磨掉机器折线感，同时保证环线闭合。
4. **四层 AR(1) 噪声**：ρ = 0.997 / 0.970 / 0.850 / 0.550，对应分钟级漂移、
   十几秒摆动、秒级毛糙。
5. **稀疏野点**：小毛刺 / 硬毛刺 / 三角形绕行包 / 大跳，尺度按总时长换算。
6. **越界不硬拽**：沿「基准点 → 噪声点」二分回缩，只削掉越界那一小段，保住毛刺形状。

### 测试覆盖

`cargo test` 跑了 9 项，全部通过：

- 2 km 轨迹距离误差 < 3%，实测配速落在允许窗口内
- 100% 点落在电子围栏内（光滑 / 毛刺两种模式）
- 禁跑区内 **0 个点**
- 同一 seed 逐点一致；不同 seed 形状必然不同
- 退化输入（空多边形 / 零配速）被拒绝
