# 小雨run · XiaoYu Run

> 极简、克制的校园运动客户端。轨迹计算与协议全部在本地完成。

**v3 是完整重写：Rust + Tauri。** 原 Android/Kotlin 实现保留在 `app/`（v2 线，仍可用）。

## 两个客户端

| | 路径 | 技术栈 | 说明 |
|---|---|---|---|
| **桌面版（当前主线）** | [`desktop/`](desktop/) | Rust + Tauri 2 + TypeScript | 轨迹引擎与协议全部在 Rust 侧，前端只做呈现 |
| 安卓版（v2） | [`app/`](app/) | Kotlin + 原生 View | 手机揣兜里的那套前台服务方案，保留不动 |

---

## 桌面版为什么值得重写

| | Kotlin 版 | Rust 版 |
|---|---|---|
| 轨迹生成 | 二分标定 70 次 × 上千点，几百毫秒到数秒 | 同样算法，**亚毫秒级** |
| 交互 | 参数改完点「开始」才知道结果 | 拖动配速/距离，轨迹形状**立刻重算重绘** |
| 保活 | 前台服务 + WakeLock + 电池白名单 | 普通进程，没有这些约束 |
| 部署 | 打包 APK、装手机 | 单个 `.app`，4.4 MB |

Rust 版真正的红利是**实时预览**：围栏、轨迹、配速窗口在参数变化时即时反馈。
原来的实现做不到这点，所以参数基本靠猜。

## 快速开始

```bash
cd desktop
npm install
npm run app          # 开发模式
npm run app:build    # 打包 .app  → src-tauri/target/release/bundle/macos/
```

首次打开会看到**内置示例跑道**的实时轨迹预览（不需要任何账号）。
填入 OpenID 后点「保存并同步场地」，即切换为真实场地围栏。

### 拿到 OpenID

在电脑端微信打开一次「重邮智慧体育」小程序并完成绑定，然后：

```bash
python3 tools/get_openid.py
```

## 轨迹引擎

同构移植自 v1.11 的 Kotlin 实现，但用显式结构体替代闭包捕获。

1. **配速标定** — 采样点数由「配速 × 距离」唯一确定（2 km @ 5'45" = 690 点），
   二分反解地面步长，使实测距离等于目标距离
2. **围栏内缩** — 从 0.90 逐档向内试，取第一个完全合法的基准环
3. **有机化** — 六条整数圈正弦 + 局部鼓包 + 滑动平均，磨掉折线感且保证闭合
4. **四层 AR(1) 噪声** — ρ = 0.997 / 0.970 / 0.850 / 0.550
5. **稀疏野点** — 小毛刺 / 硬毛刺 / 三角形绕行包 / 大跳
6. **越界不硬拽** — 沿「基准点 → 噪声点」二分回缩，保住毛刺形状
